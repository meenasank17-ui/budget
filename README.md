# smart-budget-analyzer

A command-line Python application that allows users to log expenses,
categorize spending, and receive warnings when budget limits are exceeded.

## Concepts Used
- While loops and for loops
- Conditional logic (if / elif / else)
- Dictionaries and lists
- Input validation and error handling
- Percentage calculations and aggregate analysis
- Guard conditions to prevent division by zero
- Multi-pass iteration over data structures

## Features
- Categorized expense tracking
- Percentage breakdown of total spending
- Budget limit warnings by category
- Continuous user interaction via loop-based menu

This project is part of my effort to refresh Python fundamentals
through hands-on, real-world problem solving.
